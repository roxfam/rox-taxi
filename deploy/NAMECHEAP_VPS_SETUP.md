## 1 · Right after purchase (5 min)

You'll get an email from `noc@namecheap.com` with:

**Save these somewhere secure (password manager).**

### 1a · Access Namecheap Virtualizor
1. Log in at Namecheap → Account → *Dashboard* → *VPS List* → click your server.
2. Click **"Manage"** → opens the Virtualizor control panel.
3. Verify VPS status = **Running** (green).
4. If OS isn't Ubuntu 22.04, click *Reinstall* → pick **Ubuntu 22.04 LTS 64-bit** → confirm. Wait 3-5 min.

### 1b · First SSH connection

**On Windows:** install [PuTTY](https://putty.org) or use Windows Terminal → `ssh root@198.xx.xx.xx`
**On Mac/Linux:** open Terminal → `ssh root@198.xx.xx.xx`

Enter your root password. First login prompts for a new password — pick a strong one and save it.

### 1c · Basic security hardening (2 min)

```bash
# Update everything
apt update && apt upgrade -y

# Create a non-root user (safer for daily use)
adduser rox            # answer prompts, set a strong password
usermod -aG sudo rox
mkdir -p /home/rox/.ssh && chmod 700 /home/rox/.ssh

# (Optional) Copy your local SSH key so you can login without password
# From YOUR laptop, not the server:
#   ssh-copy-id rox@198.xx.xx.xx

# Enable firewall — allow web + SSH only
ufw allow OpenSSH
ufw allow 80/tcp
ufw allow 443/tcp
ufw --force enable

# (Optional) Disable root SSH once you can login as `rox`
# sed -i 's/#PermitRootLogin.*/PermitRootLogin no/' /etc/ssh/sshd_config
# systemctl restart ssh
```

## 2 · Install the runtime (10 min, one-shot)

Copy-paste this whole block:

```bash
# System packages
sudo apt install -y \
  python3.11 python3.11-venv python3-pip python3-dev build-essential \
  nginx certbot python3-certbot-nginx \
  git curl wget unzip supervisor \
  nodejs npm

# yarn (frontend)
sudo npm install -g yarn

# MongoDB 7 — from official Mongo repo
curl -fsSL https://www.mongodb.org/static/pgp/server-7.0.asc | sudo gpg -o /usr/share/keyrings/mongodb-server-7.0.gpg --dearmor
echo "deb [arch=amd64,arm64 signed-by=/usr/share/keyrings/mongodb-server-7.0.gpg] https://repo.mongodb.org/apt/ubuntu jammy/mongodb-org/7.0 multiverse" | sudo tee /etc/apt/sources.list.d/mongodb-org-7.0.list
sudo apt update && sudo apt install -y mongodb-org
sudo systemctl enable --now mongod

# Verify
python3.11 --version   # → 3.11.x
node --version         # → 20.x or 18.x
mongod --version       # → 7.0.x
nginx -v               # → nginx/1.24+
```

If Mongo won't start (`sudo systemctl status mongod`), it's usually because the VPS is under 2GB RAM. Upgrade to Magnetar, OR skip local Mongo and use free MongoDB Atlas (see Path 3 in main RECOMMENDATIONS.md).

## 6 · Nginx reverse proxy + HTTPS (10 min)

```bash
sudo tee /etc/nginx/sites-available/roxtaxi <<'EOF'
server {
    listen 80;
    server_name roxtaxi.com www.roxtaxi.com;

    root /opt/rox/frontend/build;
    index index.html;

    # ── Backend API ───────────────────────────────────────
    location /api/ {
        proxy_pass http://127.0.0.1:8001;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 300s;       # allow Claude AI streaming
        proxy_send_timeout 300s;
        proxy_buffering off;           # stream Server-Sent Events
    }

    # ── User-uploaded photos ─────────────────────────────
    location /uploads/ {
        alias /opt/rox/backend/uploads/;
        access_log off;
        expires 30d;
    }

    # ── React SPA fallback ───────────────────────────────
    location / {
        try_files $uri $uri/ /index.html;
    }

    # ── gzip for smaller downloads ───────────────────────
    gzip on;
    gzip_types text/plain text/css application/javascript application/json image/svg+xml;
    gzip_min_length 1024;

    client_max_body_size 25M;   # allow up-to-25MB image uploads
}
EOF

sudo ln -sf /etc/nginx/sites-available/roxtaxi /etc/nginx/sites-enabled/roxtaxi
sudo rm -f /etc/nginx/sites-enabled/default
sudo nginx -t                    # test config
sudo systemctl reload nginx
```

### Point your domain at the VPS
- Namecheap → Domain List → *Manage* → **Advanced DNS** tab
- Delete existing A/CNAME rows for `@` and `www`
- Add:
  - Type=`A Record`, Host=`@`, Value=`198.xx.xx.xx` (your VPS IP), TTL=Auto
  - Type=`CNAME`, Host=`www`, Value=`roxtaxi.com`, TTL=Auto
- Save. DNS propagates in 5-30 min. Check with `dig roxtaxi.com` on your laptop.

### Free HTTPS with Let's Encrypt

Once DNS resolves to your VPS:
```bash
sudo certbot --nginx -d roxtaxi.com -d www.roxtaxi.com \
  --non-interactive --agree-tos -m roxfam2509@gmail.com --redirect
```

That auto-adds SSL certificates and rewrites nginx config to force HTTPS. Renewal is automatic via cron.

## 7 · Run the FastAPI backend forever (5 min)

Use Supervisor so the backend restarts on crash + on reboot:

```bash
sudo tee /etc/supervisor/conf.d/rox-backend.conf <<'EOF'
[program:rox-backend]
command=/opt/rox/backend/venv/bin/uvicorn server:app --host 127.0.0.1 --port 8001 --workers 2
directory=/opt/rox/backend
environment=PATH="/opt/rox/backend/venv/bin"
autostart=true
autorestart=true
stdout_logfile=/var/log/rox-backend.log
stderr_logfile=/var/log/rox-backend.err.log
user=root
EOF

sudo supervisorctl reread
sudo supervisorctl update
sudo supervisorctl status rox-backend
# → rox-backend    RUNNING   pid xxxxx, uptime 0:00:03
```

If it says `FATAL`, tail the log:
```bash
sudo tail -n 50 /var/log/rox-backend.err.log
```

## 9 · Ongoing maintenance (5 min per month)

### Weekly backup — add to crontab
```bash
sudo crontab -e
# Add these lines:
0 3 * * 0  mongodump --db test_database --out /opt/rox/backups/mongo_$(date +\%Y\%m\%d) && find /opt/rox/backups -mtime +30 -type d -exec rm -rf {} +
0 4 1 * *  apt update && apt upgrade -y   # monthly security patches
```

### Deploying a code update
```bash
cd /opt/rox
git pull
# If backend changed:
source backend/venv/bin/activate && pip install -r backend/requirements.txt && deactivate
sudo supervisorctl restart rox-backend
# If frontend changed:
cd frontend && yarn install && yarn build
sudo systemctl reload nginx
```

### Health check commands
```bash
sudo supervisorctl status         # backend running?
sudo systemctl status nginx       # nginx running?
sudo systemctl status mongod      # mongo running?
tail -n 100 /var/log/rox-backend.log
```

### If something's wrong
```bash
# Restart everything
sudo systemctl restart mongod
sudo supervisorctl restart rox-backend
sudo systemctl reload nginx

# Full reboot (last resort)
sudo reboot
```

## 11 · Common issues + fixes

| Symptom | Fix |
|---|---|
| `502 Bad Gateway` on `/api/*` | Backend crashed. `sudo supervisorctl status rox-backend` + tail log. |
| SPA shows blank white page | Nginx couldn't find `frontend/build/`. Re-run `yarn build` and check nginx `root` path. |
| `MongoServerError: connect ECONNREFUSED 127.0.0.1:27017` | Mongo not running. `sudo systemctl start mongod`. Under 2GB RAM = upgrade to Magnetar. |
| Certbot fails | DNS hasn't propagated. Wait 30 min. Check `dig roxtaxi.com`. |
| Emails not arriving | SPF + DKIM DNS records not set. Namecheap Private Email support has one-click setup. |
| SMS not sending | Twilio `TWILIO_FROM_NUMBER` isn't a purchased number (trial numbers don't work in prod). |
| Slow site | Upgrade to Magnetar (4GB) or add Cloudflare in front (free CDN). |

## 12 · When to upgrade (Magnetar / Quasar)

Move to Magnetar when any of:
- MongoDB uses > 1.5GB RAM (`db.serverStatus().mem`)
- More than 200 concurrent visitors
- More than 500 bookings/day
- Response times exceed 500ms consistently

Upgrade in Namecheap panel takes 5 min + a reboot — data preserved.
